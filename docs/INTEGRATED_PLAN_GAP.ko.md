# 통합 기획안 대비 구현 갭 보고서

기준 문서는 사용자가 제공한 **AI 자율형 생방송 콘텐츠 제작 시스템 통합 v1**이며, 저장소의 현재 `main` 계열 구현을 기능 단위로 대조했다. “계약과 테스트가 있음”과 “실제 AI 모델·6시간 영상으로 검증됨”을 구분한다.

## 이번 변경에서 닫은 갭

1. **MVP 1 YouTube Content Intelligence 저장소**: 공개 메타데이터와 구조·편집·스토리텔링·장면 선택·페이싱·자막·제목/썸네일 관계·제작 논리를 검증해 SQLite에 저장한다.
2. **저작권·약관 경계**: 레퍼런스 원본 파일은 DB 스키마에 넣지 않는다. 타 채널의 유지율·CTR·재시청 구간 같은 비공개 Analytics 필드는 거부한다.
3. **외부 분석기 계약**: `--input`/`--output` JSON 계약으로 실제 모델을 교체할 수 있고, 결과가 필수 제작 지식을 충족해야 저장한다.
4. **실제 UI 연결**: 콘텐츠 지식 화면은 fixture가 아니라 `/api/youtube/references` 결과를 표시한다.
5. **직전 보안·호환성 수정 유지**: Python 3.11 자막, dist 전용 정적 서빙, POST 500 JSON, WAL/busy timeout, import-safe app factory, 안전한 token 파일 생성 및 브라우저 미디어 업로드를 새 브랜치에 포함한다.

|---|---|---|

| MVP 2 멀티모달/장기 이해 | orchestration 계약 구현 | WhisperX·비전·화자분리 모델 설치 및 4~6시간 실측 필요 |

## 완료율 판단

코드 계약과 로컬 단위 테스트의 범위는 넓지만, 통합 기획안의 성공 기준은 **실제 모델과 실제 4~6시간 방송, 사람 정답셋, 실제 편집기, 실제 YouTube 자격 증명**을 요구한다. 따라서 현재 상태를 “100% 완성” 또는 “기획안 80% 실증 완료”라고 선언할 수 없다. 이후 진행률은 파일 수가 아니라 MVP별 성공 기준을 통과한 증거로 계산해야 한다.

## 다음 구현 우선순위

1. 실제 레퍼런스 데이터셋 20~50편으로 MVP 1 사람 평가 리포트 생성
2. 실제 4~6시간 원본으로 처리시간·사건 recall 측정
3. 후보 검수 결과를 discovery 평가셋으로 export하는 기능
4. 원본↔완성본 자동 정합 matcher
5. 그래픽/BGM/효과음 및 얼굴 좌표 기반 렌더 명세
6. 설치된 Premiere/Resolve/Blender에서 end-to-end 검증
