## 병합 기준

- 기능 브랜치 기준 커밋: `3dacfdd`
- 병합한 `main` 기준 커밋: `e6fd46b`

- 충돌 해결 파일: `backend/server.py`, `src/main.js`, `tests/test_server_runtime.py`

충돌 해결본은 Content Intelligence API, 에피소드 기반 Source-to-Output 학습,
런타임 기반 콘텐츠 지식 화면과 양쪽의 서버 통합 테스트를 모두 유지한다.

## 로컬 시작

```bash
npm install
npm run api
# 별도 터미널
npm start
```

프로덕션 번들 확인은 `npm run build`, 전체 검증은 `npm test`와
`npm run check:pr`을 사용한다. Python 코어는 3.10 이상을 사용한다.

## 남은 작업

### P0 — 데스크톱 실행 기반

- Electron main/preload와 context-isolated IPC를 추가한다.
- Python API를 sidecar로 시작·감시·종료하고 포트와 API 키를 안전하게 전달한다.
- 운영체제 파일 선택기로 MP4/MKV 실제 경로를 전달한다.
- DB, 로그, 모델 캐시, 임시 파일과 렌더 결과를 OS 사용자 데이터 폴더로 옮긴다.
- Windows/macOS 설치 패키지와 런타임 의존성 검사를 만든다.

### P1 — 실제 멀티모달 분석기

- WhisperX 기본 실행기, 단어 타임스탬프, chunk 중복 제거와 멀티트랙 처리를 완성한다.
- 통화 트랙에만 선택적인 화자 분리를 적용하고 실패 시 `UNKNOWN`으로 진행한다.
- 웃음·비명·환호·침묵·BGM 변화 등 오디오 관찰 실행기를 구현한다.
- 얼굴·표정·OCR·채팅·후원·게임 UI 변화 등 비전 관찰 실행기를 구현한다.
- 모델 설치, GPU/CPU 선택, VRAM 부족, 다운로드와 취소 UI를 추가한다.

### P2 — 장기 방송 이해와 콘텐츠 발견

- 1차 전체 통과의 누적 memory와 사건·인물 식별자 병합을 구현한다.
- 불확실 구간을 선정해 2차 정밀 분석하고 사건 그래프를 갱신한다.
- 시간적으로 떨어진 mention을 같은 사건으로 연결하고 근거 타임스탬프를 강제한다.
- 사건 기준으로 `MAKE/COMBINE/HOLD/REJECT`를 판단하며 `NO_CONTENT`를 정상 종료로 유지한다.
- 사람이 놓친 사건, 잘못 연결된 장면과 후보 결정을 수정할 수 있게 한다.
- 콘텐츠 발견 precision, recall과 오탐률을 실제 방송 데이터셋으로 측정한다.

### P3 — 검색·기획·페이싱

- STT, OCR, 인물, 오디오 사건과 event mention의 검색 인덱스를 구축한다.
- 최초 언급·반응·갈등·결과 장면을 검색하고 AI 재검증 및 선택 근거를 저장한다.
- 고정 구조 없이 콘텐츠별 비선형 컷 순서와 편집 의도를 생성한다.
- 목표 길이는 힌트로만 사용하고 다른 결과를 선택한 이유를 기록한다.
- `KEEP/TRIM/CUT`을 문맥으로 판단하고 모든 기준값을 채널 캘리브레이션에서 받는다.
- 계획 JSON의 스키마 버전, 수정 이력과 사람 검토 UI를 추가한다.

### P4 — Content Intelligence와 학습 루프

- YouTube URL 등록, 공개 메타데이터 수집과 레퍼런스 분석 작업 큐를 구현한다.
- 임시 레퍼런스 미디어 폐기와 실패 후 청소를 검증한다.
- 영상 구조·컷·스토리·자막·제목·썸네일의 근거 기반 패턴 추출기를 구현한다.
- 제작 패턴을 후보와 유사도 검색해 planning 입력에 연결하고 적용·미적용 이유를 저장한다.
- 원본과 완성본을 fingerprint로 자동 정렬해 선택·제거·반복·재배치 데이터를 만든다.
- 성과 데이터는 표본 기준과 사람 승인을 통과한 전략만 다음 기획에 반영한다.

### P5 — 렌더·자막·패키징

- 1080p/4K, VFR, HDR/SDR, 멀티트랙과 수백 컷 타임라인을 실제 미디어로 검증한다.
- A/V sync, 컷 경계 노이즈, 2-pass EBU R128과 CPU/GPU 인코더 fallback을 검증한다.
- 얼굴 추적 crop의 segment, `sendcmd`/`zoompan`, 프레임 합성 방식을 실측해 하나를 채택한다.
- ASS 스타일 편집, 폰트 라이선스, 한국어 fallback, SRT와 편집기 자막 import를 완성한다.
- 제목 후보 3개, 설명, 태그, 챕터와 중복 제거된 썸네일 후보를 생성한다.
- 렌더·패키징 실패 시 앞 단계 산출물을 보존하고 해당 단계만 재실행한다.

### P6 — UI와 검수·업로드

- 남아 있는 fixture 통계와 데모 로그를 실제 API 데이터로 교체한다.
- 레퍼런스 가져오기, 패턴 검색·필터·근거 보기와 로그 내보내기를 연결한다.
- 후보 결합·제외·추가, 편집 계획 수정, 제목·썸네일 선택을 연결한다.
- 단계별 진행률, 현재 처리 구간, 예상 시간, 자원 사용량, 취소·재개를 표시한다.
- 검수 승인 전 공개를 차단하고 PRIVATE/UNLISTED, 썸네일, 예약 공개를 실제 채널에서 검증한다.
- OAuth 만료, 네트워크 단절, resumable upload와 PT 자정 quota 재시도를 E2E 테스트한다.

### P7 — 편집기 연동

- Premiere, Resolve와 Blender에서 선택 미디어 전달과 background job polling을 실제 버전별로 검증한다.
- 결과 미디어, 컷 타임라인, 오디오 트랙과 자막을 각 편집기로 import한다.
- FCPXML, EDL, CSV의 frame rate, drop-frame timecode와 round-trip을 검증한다.
- 공개 플러그인 계약이 없는 편집기는 MP4/SRT/CSV 교환 방식과 제한을 명확히 표시한다.
- 플러그인 설치·제거, 앱 탐색, bridge 인증과 버전 호환성 표를 제공한다.

### P8 — 데이터·보안·운영 품질

- 명시적인 DB schema version과 트랜잭션 기반 migration/rollback을 추가한다.
- OS credential store, 로그 secret 제거, 외부 실행기 allowlist와 IPC 인증을 적용한다.
- 프로젝트·모델 캐시·임시 미디어·Analytics의 보존 및 삭제 정책을 구현한다.
- disk full, 권한 오류, 손상 미디어, 잘못된 AI JSON과 외부 실행기 hang을 시험한다.
- 4·6·10시간 원본의 처리 시간, 비용, 디스크, RAM/VRAM을 하드웨어별로 측정한다.
- 강제 종료 복구, SQLite 동시성, 취소 race와 장시간 soak 테스트를 CI/실기에서 수행한다.
